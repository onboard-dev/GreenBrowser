# GreenBrowser

Windows 11向けの動画サムネイルブラウザです。
最新のコーデックにも対応できるよう、サムネイル生成には都度ダウンロードする最新のFFmpegを使用します。
ボイスコントロール、再エンコードしないMP4編集、プレイヤー内蔵
![](docs/Guide.png)

## ダウンロードと起動

[Releases](https://github.com/onboard-dev/GreenBrowser/releases) から最新の `GreenBrowser-vX.Y.Z-win-x64.zip` を
ダウンロードし、好きな場所に展開して `GreenBrowser.exe` を実行してください。インストールは不要です。

動作環境: Windows 11(64bit)と、
[.NET 8 デスクトップ ランタイム(x64)](https://dotnet.microsoft.com/download/dotnet/8.0) が必要です。

ソースコードは公開していません。このリポジトリには、この説明(README)と、Releases で配布するファイルだけを置いています。

## 主な仕様

1. メイン画面は動画のサムネイル一覧。サムネイルは動画を3分割した位置から自動生成される
   540x140pxのフィルムストリップ画像で、右クリックメニューからいつでも手動で再生成できるほか、
   ファイルのコーデック情報を見る「プロパティ」や、保存場所をエクスプローラーで開く項目もあります。
   「サムネイルと位置の変更…」を選ぶと、動画を実際に再生しながら3コマの抽出位置を
   手動で指定し直すことができます(WhiteBrowserと同様)。一度指定した位置は保存され、
   以後のホイールクリックでのシーンジャンプもその位置を使うようになります。
   サムネイルの下(10pt)にファイル名・星の数・再生数を表示します。
2. サムネイルをダブルクリックすると動画を再生します。ホイールクリック(中央クリック)すると、
   クリックした位置に表示されているコマの実際の時刻から再生します。再生するたびに再生数を+1して
   記録します。再生中に別の動画をダブルクリック(またはホイールクリック)した場合は、
   最後に操作したほうだけが再生されます(古いプレイヤー画面は自動的に閉じます)。
3. スキン機能・拡張機能は廃止し、レイアウトは1種類(defaultSmall相当)に固定しています。
4. 星の表示をクリックすると1〜5の評価を付けられます(同じ数を再クリックで未評価に戻ります)。
   ツールバーの「★n」ボタンで、ちょうどその星の数が設定されているファイルだけに絞り込めます。
5. 指定したフォルダ(サブフォルダ含む)を監視し、新しい動画ファイルは自動的に一覧に追加されます。
   ツールバーの「フォルダ管理…」から監視フォルダを複数登録・編集・削除できます(登録した全フォルダの動画が1つの一覧にまとめて表示されます)。
6. ツールバーの「並び順」で「作成日(新しい順)」「星の数(多い順)」「再生数(多い順)」を切り替えられます。
7. 内蔵プレイヤーは全画面表示(ボタンまたはF11、Escで解除)、←→キーで±5秒シーク、↑↓キーで±10秒シーク、
   マウスホイールで音量調整に対応しています。シークバーはツマミ以外の場所をクリックしてもその位置に
   ジャンプでき、ツマミをドラッグしている間も継続してシークします。
8. サムネイルを左クリックすると選択状態になり(緑色の枠で表示)、その状態でDeleteキーを押すか、
   右クリックメニューの「ファイルを削除」を選ぶと、確認の上でそのファイルを削除できます。
   削除は完全消去ではなく「ごみ箱」への移動なので、誤って削除した場合はエクスプローラーの
   ごみ箱から復元できます。
9. 右クリックメニューの「MP4に変換(最新コーデックで再エンコード)」を選ぶと、そのファイルを
   映像H.264/音声AACのMP4として同じフォルダ内に再エンコードします(ファイル名は
   `元のファイル名_converted.mp4`)。古いWMV/ASF等でシークが不安定になったり、長さの
   メタデータが壊れていたりする問題は、コンテナ・コーデックそのものに起因していることが多いため、
   そうした問題のあるファイルに気づいた場合の根本的な対処として使えます。元のファイルは
   変換後も自動的には削除されません(必要であれば上記の削除機能で手動で削除してください)。
   PCにNVIDIA/Intel/AMDのGPUが搭載されていて、そのハードウェアエンコード機能が使える場合は
   自動的にそちらを使い(NVENC→Quick Sync→AMF→ソフトウェアエンコードの順に実際に試して、
   最初に成功したものを使う)、変換完了時のメッセージにどれが使われたかが表示されます。
   進捗(%)はステータスバーに表示され、変換後の新しいファイルはフォルダ監視の仕組みにより
   自動的に一覧に追加されます。GPUエンコードには比較的新しいグラフィックドライバが必要で、
   ドライバが古い・非対応の場合は自動的にCPUエンコードへ切り替わります(変換自体は問題なく
   行われますが時間がかかりやすくなります)。
10. 内蔵プレイヤーに「A-B区間の繰り返し再生」機能があります。区間は複数設定できます。
    一時停止ボタンの右側にある「👉」を押すと現在位置が区間の開始点になり、続けて「👈」を
    押すと現在位置が終了点となって、1つの区間として追加されます。これを繰り返すと、
    何区間でも追加できます(重なった区間は自動的に1つにまとまります)。各区間は、
    開始点が緑の縦線+番号、終了点が赤の縦線、範囲が緑色の帯でシークバー上に表示されます。
    この状態で「🔄 繰り返し」ボタンを押す(オンにする)と、区間を1→2→3…の順に再生し、
    最後の区間が終わったら最初の区間に戻って再生を続けます(いま何番目の区間かは
    ボタンの右に表示されます)。区間の外を自分でシークして再生したときは、そのまま再生され、
    区間に入って終了点に達したところから繰り返しに戻ります。「➖」ボタンは、開始点だけ
    設定中ならそれを取り消し、そうでなければ現在位置を含む区間を削除します。「🧹」ボタンで
    すべての区間と有効/無効の設定をまとめて削除できます。繰り返しが有効な状態で保存されている
    ファイルは、次回そのファイルを開いたときも(サムネイルのシーンジャンプ位置などより優先して)
    必ず最初の区間の開始点から再生が始まります。繰り返し設定済み(かつ有効)のファイルは、
    メイン画面のファイル名の左側に青い「🔄」バッジが表示されます。以前のバージョンで
    設定した1区間は、そのまま1つ目の区間として引き継がれます。
11. 右クリックメニューの「✂️ 必要な部分だけを抽出(ロスレス編集・MP4のみ)…」を選ぶと、
    LosslessCutのように、再エンコードなし(ストリームコピー)で必要な部分だけを切り出して
    結合できる専用の編集ウィンドウが開きます。動画を再生しながら「👉 区間開始」
    「👈 区間終了」(キーボードの I / O キーでも可)で範囲を指定し、「➕ 追加」で
    書き出しリストに追加します。複数の区間を追加できるほか、リスト上の⬆⬇ボタンで
    結合順を入れ替えたり、🗑ボタンでリストから外したりできます。「🎬 書き出し」を押すと
    保存先を選び、リストの区間を順番に切り出して1つのファイルに結合します(区間が1つだけの
    場合はそのまま切り出すだけ)。再エンコードを行わないため画質の劣化がなく処理も高速ですが、
    切り出しの開始位置は直前のキーフレームに合わせられるため、場合によっては数秒前後ずれる
    ことがあります。この機能はMP4ファイルのみに対応しています。wmv/asf等の古い形式の
    ファイルはコーデックの都合でこの方式(再エンコードなし)での切り出しがうまく行えないため、
    メニューを選ぶと警告が表示されそれ以上進めません。まず「MP4に変換」でMP4化してから、
    変換後のファイルに対してお使いください。

評価・再生数・サムネイルのキャッシュは、開いたフォルダ内の隠しフォルダ `.greenbrowser` に保存されます
(WhiteBrowserと同様、フォルダを移動してもデータが一緒についてきます)。

## FFmpegについて

サムネイル生成用の `ffmpeg.exe` / `ffprobe.exe` はアプリのファイルには含まれておらず、
初回起動時にインターネット経由で自動的にダウンロードします
(保存先: `%LocalAppData%\GreenBrowser\tools`)。

GitHub (github.com) への接続がブロックされている環境では自動ダウンロードに
失敗します。その場合は下記などから `ffmpeg.exe` と `ffprobe.exe` を入手し、上記フォルダに
手動で配置してください。

- https://www.gyan.dev/ffmpeg/builds/ (「essentials」または「full」のbuild内のbinフォルダにあります)

## 既知の制限・今後の改善余地

- サムネイル一覧はまだ「仮想化」を行っていない簡易実装のため、1フォルダに数千本の動画がある場合は
  スクロールがやや重くなることがあります。数百本程度までは軽快に動作します。
- 複数フォルダは「まとめて1つの一覧」に表示する方式です(WhiteBrowserのようなフォルダツリーでの
  階層ナビゲーション/切り替え表示は今回は実装していません)。必要であれば追加できます。
- 再生は内蔵プレイヤー(WPF MediaElement / Windows Media Foundation)を使用します。
  非常に特殊なコーデックの動画は、Windowsの「メディア機能拡張」の追加インストールが必要な場合があります。
